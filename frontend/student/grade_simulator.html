How this works

We compute a credit-weighted average across every course in your record using the grade points you select on the left. Letter grades map to a 10-point scale (A/A+ = 10, B+ = 9, B = 8, …, F = 0).

This is a what-if tool only; nothing here is saved to your transcript.
